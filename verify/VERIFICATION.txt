一、根因（已实测复现）
--------------------------------------------------------------
1) 编码池瞬间 503
   上游 HlsJobs.create() 在槽位占满时立刻抛
     HTTPException(503, "Desktop encoder is busy; retry shortly")
   默认 max_workers=2、max_jobs=4。
   切换下一集时，旧任务仍在收尾（未被标记取消 / 未 done），
   于是新一集直接吃 503。前端只在 200ms 后重试一次，仍失败 →
   界面显示「播放中断，请重试当前集。／第 N 集 · 媒体准备失败」。

   复现（真实进程内，直接打本机 HLS 接口）:
     POST ep=901 -> 200
     POST ep=902 -> 200
     POST ep=903 -> 503
     POST ep=904 -> 503
     POST ep=905 -> 503
     POST ep=906 -> 503

   真实会话抓包（修复前，WebView 网络事件）:
     POST ?series_id=...&ep=745 -> 503
     POST ?series_id=...&ep=746 -> 503
     POST ?series_id=...&ep=744 -> 503
   与用户截图「第 728/1000 集 · 媒体准备失败」一致。

2) 打包后白屏
   上游每次发版会更换 Vite 产物哈希文件名（如 index-CEHZDRVO.js）。
   安装包内的 index.html 与 exe 内嵌资源不同批时，
   index.html 仍引用旧文件名 → 脚本 404 → 页面全白。
   实测控制台报错:
     Failed to load module script: Expected a JavaScript-or-Wasm module
     script but the server responded with a MIME type of "text/html".
   修复前 exe 内 index.html 引用 /assets/index-CEHZDRVO.js，
   而实际键为 /assets/index-Bm6fM3_d.js。

3) 部署脚本漏文件
   tools/deploy.ps1 只同步 server.py / desktop_hls.py /
   desktop_hls_service.py，从未同步 desktop_encode.py。
   后端补丁给 encode_h264 增加了 cancelled 形参，
   但旧版 desktop_encode.py 不接受该参数 → 取源阶段抛
   TypeError → 同样表现为「媒体准备失败」。

--------------------------------------------------------------
二、修改点
--------------------------------------------------------------
A. desktop_hls_service.py
   - 新增 queue_wait（默认 8.0s）；create() 改为有界排队：
     槽位满时等待，而不是立刻 503。
   - 占用判定把「已取消、尚未收尾」的任务排除：
       live   = 未取消的任务数        < max_jobs
       active = 未完成且未取消的任务数 < max_workers
   - max_jobs 4→6、max_workers 2→3。
   - source_loader 调用透传 cancelled=job.cancelled.is_set，
     使切集时旧任务能立刻停下；对只收 3 个参数的旧实现回退兼容。

B. desktop_encode.py
   - encode_h264(source, cancelled=None)；
     demux 循环内检测取消，命中即抛错停止转码，
     不再让已放弃的任务长时间占着编码槽位。

C. server.py
   - _desktop_source(series_id, episode, quality, cancelled=None)
     把 cancelled 继续传给 encode_h264。

D. app.js（前端）
   - 新增 hqPost(run, aborted)：对开场 POST 做最多 6 次、
     指数退避（250ms 递增）的重试；仅在收到 503 且未中止时重试。
   - 两处「503 后只重试一次」的旧逻辑替换为 hqPost。

E. tools/repack.py + tools/verify_repack.py + tools/auto_patch.py
   - 新增 align_index_html()：打包时把 index.html 里的
     script src / link href 重写到 exe 内真实存在的资源键，
     版本无关，杜绝白屏。

F. tools/deploy.ps1 + tools/restore.ps1 + tools/auto_patch.py
   - 同步/备份文件清单补齐 desktop_encode.py。
